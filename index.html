Как пользоваться

01 / PREPARE

Выберите список

Рядом с BAT уже есть digits.txt: одна запись из четырёх цифр на строку. Начальные нули сохраняются; файл можно заменить своим.

02 / START

Выберите действие

Запустите BAT. Через меню можно запустить управление, сбросить указатель, пропустить запись или просмотреть список.

03 / CONTROL

Пауза и продолжение

Правый Shift ставит цикл на паузу и продолжает с текущего шага. Скрипт вводит цифры по одной и нажимает Enter.

Полная инструкция

01 / ПОДГОТОВКА

Подготовь файлы

  1. Распакуй ZIP в одну папку.
  2. Положи RustMacroControl.bat и digits.txt рядом.
  3. В digits.txt должна быть хотя бы одна строка ровно из четырёх цифр. Каждая запись — с новой строки; нули в начале сохраняются. Строки другого формата пропускаются.
  4. Запусти BAT двойным щелчком. Не запускай вторую копию, пока уже открыта первая.
02 / ГЛАВНОЕ МЕНЮ

Выбери пункт цифрой

  1. 1 — открыть панель управления.
  2. 2 — сбросить указатель списка на первую запись.
  3. 3 — пропустить следующую запись.
  4. 4 — открыть нумерованный список.
  5. 0 — закрыть программу.
03 / ЗАПУСК И ПАУЗА

Управляй макросом

  1. Переключись в Rust и нажми Right Shift, чтобы начать цикл. Макрос отправляет ввод в активное окно.
  2. Right Shift ставит цикл на паузу и продолжает с текущего шага.
  3. Когда окно BAT в фокусе, в панели управления клавиша 1 запускает/продолжает, 2 сбрасывает список, 3 пропускает запись, 4 открывает список.
  4. Для выхода верни фокус на окно BAT и нажми 0. Right Shift — пауза, он не закрывает программу.

Один цикл выполняет настроенную последовательность с клавишей E, движением мыши, кликом, вводом четырёх цифр и Enter.

04 / СПИСОК И ПРОГРЕСС

Просмотр и продолжение

  1. В меню нажми 4. На странице показывается до 25 записей.
  2. Введи 1 — следующая страница, 2 — предыдущая, 0 — выход из просмотра.
  3. Пункт 2 главного меню сбрасывает указатель в начало; пункт 3 сдвигает его на одну запись.
  4. Файл .digits-index рядом с BAT хранит позицию списка. Не удаляй его, если нужно продолжить с сохранённого места. Позиция обновляется после завершения полного цикла.
