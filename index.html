Как пользоваться

01 / PREPARE

Выберите список

Рядом с BAT уже есть digits.txt: одна запись из четырёх цифр на строку. Начальные нули сохраняются; файл можно заменить своим.

02 / START

Выберите действие

Запустите BAT. Через меню можно запустить управление, сбросить указатель, пропустить запись или просмотреть список.

03 / CONTROL

Пауза и продолжение

Правый Shift ставит цикл на паузу и продолжает с текущего шага. Скрипт вводит цифры по одной и нажимает Enter.

Файлы

  • RustMacroControl.bat — программа и меню
  • digits.txt — опубликованный список для макроса
  • digits.example.txt — небольшой пример формата

Использование списка

Список опубликован вместе с проектом. При необходимости замени digits.txt своим файлом с четырёхзначными строками.
